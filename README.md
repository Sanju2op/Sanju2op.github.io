# Portfolio

Source for https://sanju2op.github.io/ — the portfolio of Sanjay Lagariya, a full-stack developer.

Built with [Astro](https://astro.build) and deployed to GitHub Pages with GitHub Actions.

## Develop
```
npm install
npm run dev
```

## Edit content
Projects, skills, timeline, quotes and photos are all in `src/data/site.ts`.

## Docs
Start with `CLAUDE.md`, then `Docs/ARCHITECTURE.md`, `Docs/CONVENTIONS.md`, `Docs/Tasks.md` and `Docs/Design.md`.
